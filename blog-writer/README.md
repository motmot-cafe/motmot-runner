# 모토모토 블로그 원고기 — 받는 자리

사장님 PC 의 「모토모토 블로그 원고기」 가 켤 때와 6시간마다 여기의 `latest.json` 을 봅니다.
새 판이면 시작 화면 맨 위에 **「새 판이 있습니다」** 가 뜹니다. **「업데이트」 를 눌러야** 받습니다 — 누르기 전에는 아무것도 바꾸지 않습니다.

- 지금 판: **2026.09.30-2** — 개인(펜션 · 풀빌라) · 카페 원고에는 수용 정원을 쓰지 않습니다 — 객실 기준 · 최대 인원(「기준 2인 최대 4인」)을 사실에서 빼고 「몇 명까지」 질문을 고르지 않습니다
- 받는 주소(손으로 받을 때): https://raw.githubusercontent.com/motmot-cafe/motmot-runner/main/blog-writer/motmot-blog-writer-2026.09.30-2.zip
- `latest.json` — 판 번호 · 바뀐 점 · zip 주소 · sha256(zip) · exe_sha256(안의 exe) · size(zip 바이트)
- `motmot-blog-writer-2026.09.30-2.zip` — 지금 판(안에 `모토모토-블로그원고.exe` 하나)
- `motmot-blog-writer-2026.09.30-1.zip` — 바로 앞 판(되돌릴 때)

## 원고기 안에서 업데이트 (보통은 이것)

1. 시작 화면 맨 위 「새 판이 있습니다 — 판 …」 에서 바뀐 점을 읽고 **「업데이트」**.
2. 원고를 쓰는 중이면 **그 원고를 마치고** 바꿉니다(「지금 쓰는 원고를 마치고 업데이트합니다」).
3. 원고기가 잠깐 꺼졌다가 새 판으로 다시 켜지고, 새 시작 화면이 뜹니다. 바탕화면 아이콘 · PC 켤 때 자동으로 켜기는 그대로입니다.
4. 안 되면 화면에 까닭이 뜨고 **옛 판이 그대로** 돕니다(백신이 막았을 수 있습니다). 그때는 아래처럼 손으로 받습니다.

## 손으로 받아 풀기

「업데이트」 단추는 **판 2026.09.29-9 부터** 있습니다. 그 전 판(-8 까지)을 쓰고 계시면 처음 한 번만 이렇게 손으로 받습니다.

1. 위 「받는 주소」 를 눌러 zip 을 받습니다.
2. 받은 zip 을 오른쪽 클릭 → **모두 압축 풀기** → `모토모토-블로그원고.exe` 이 나옵니다.
3. 그 exe 를 원고기를 둘 폴더에 두고 **더블클릭** — 떠 있는 옛 판을 새 판이 넘겨받습니다(PC 켤 때 자동 시작 · 바탕화면 아이콘도 새 exe 를 가리킵니다).
   옛 exe 자리에 덮어쓰려면 먼저 옛 시작 화면에서 「원고기 끄기」 를 누르세요(켜져 있는 exe 는 윈도우가 못 바꾸게 막습니다).

원고기는 https 로 **이 저장소(raw.githubusercontent.com/motmot-cafe/motmot-runner/)** 에서만 받고, zip 과 안의 exe 의 sha256 이 `latest.json` 과 맞아야만 바꿉니다.
exe 에는 비밀이 없습니다(공개 anon 키와 공개 사실뿐 — 원고기 비밀은 사장님 PC 에서 처음 켤 때 만듭니다).
